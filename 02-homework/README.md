# 课程作业

老师布置的作业放这里。和教材练习（`01-textbook/`）分开，因为作业有提交期限，需要单独管理。

## 命名约定

按「第几次作业」建子目录：

```
02-homework/
├── hw01/
│   ├── problem1.c
│   └── problem2.c
├── hw02/
└── hw03/
```

如果是一次综合大作业，用有意义的名字单独建目录：

```
02-homework/
└── student-manager/     学生成绩管理系统
```

## 几个提醒

- 老师如果提供了测试数据或输入样例，一起放进对应目录
- **交完作业再回头看一遍**：当时卡住的地方、最后怎么解决的，写进 `05-notes/`
- 作业代码同样要过一遍 `-Wall -Wextra`，零警告再交
