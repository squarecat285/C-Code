# 学习笔记

## 只记三样东西，不要抄书

1. **踩过的坑** —— 比如「`scanf` 读 double 要用 `%lf`，读 float 才用 `%f`」
2. **自己搞懂了的原理** —— 比如「整数除法 `5/2` 得 2；想得小数，至少要有一个操作数是浮点」
3. **还没搞懂的问题** —— 先写下来，学到后面再回来回答

抄书没有用，笔记的价值在于**那是你自己的话**。
