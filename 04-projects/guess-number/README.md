# 猜数字游戏

自己写的第一个完整小程序，前后改了三个版本。

## 三个版本

| 版本 | 文件 | 比上一版多做了什么 |
|---|---|---|
| v1 | `v1_basic.c` | 能猜就行，不限次数 |
| v2 | `v2_limit10.c` | 限制 10 次；用数组记录猜过的数字；输了公布答案 |
| v3 | `v3_replay.c` | 提示语随机化；支持「再来一局」 |

## 每个版本用到的知识点

- **v1**：`while(1)` 无限循环、`srand(time(0))` 设置随机数种子、`rand() % 100 + 1` 生成 1~100
- **v2**：数组 `guesses[10]` 保存历史记录
- **v3**：字符串数组（提示语随机挑选）、嵌套循环、`scanf(" %c", &again)` 读字符

这三个文件连起来就是一条学习轨迹：**从「能用」到「好用」**。比只留最后那个 v3 有价值得多——将来回头看，你能清楚看到自己是怎么一步步改进的。
