# 自己做的小玩意儿

这里放**没有标准答案**的程序——不是课后题，也不是刷题，而是自己想做的东西。

这类练习最能长本事，因为没人告诉你该怎么做。

## 目前有

| 项目 | 说明 |
|---|---|
| [`guess-number/`](guess-number/) | 猜数字游戏，改过三个版本 |
| [`collatz/`](collatz/) | Collatz（3n+1）猜想：算一个数要几步跌回 1 |
| [`trailing-zeros/`](trailing-zeros/) | n! 末尾有几个连续的 0 |

## 想到什么就加什么

几个适合现在的难度、又能练到手的小东西：

- 简易计算器（练 `switch`、字符输入、除零处理）
- 九九乘法表（练嵌套循环、`%-4d` 格式对齐）
- 成绩统计（练循环 + 累加 + 极值）
- 打印日历（练多重循环）
- 大数相加（数字太大 `int` 存不下时怎么办）

每个项目建一个子目录，里面放一个 `README.md` 说明**为什么做、怎么做、踩了什么坑**。
