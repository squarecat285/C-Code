## 这一组学到的

- **「能不能过」和「对不对」是两件事。** P3954 的两个样例都过，全量一跑 194 组错；B2029 的 `(20000+v-1)/v` 五万组全对，换个 v 就错。样例是抽样，不是证明。
- **浮点是默认选项的陷阱。** 涉及小数的题，第一反应应该是「能不能全用整数算」：百分比变成 ×20 ÷100，元角变成 ×10，一次都不用 `double`。
- **时间、日期这类题，先统一成一个单位**（分钟 / 角 / 厘米），最后再拆回去，比拼凑「几时几分」省一半判断。
