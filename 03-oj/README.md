# 在线判题

按平台分子目录，目前是洛谷。

## 洛谷

https://www.luogu.com.cn/

### 命名约定

用题目编号开头，后面跟一句简短的英文描述：

```
03-oj/luogu/
├── P1001_a_plus_b.c
├── P1008_three_division.c
└── P1421_schoolwork.c
```

### 每道题的文件头

除了标准头注释，再加两行：

```
 * 题目：https://www.luogu.com.cn/problem/P1001
 * 结果：AC（第一次 WA 是因为没考虑负数）
```

**记下「第一次为什么错」比记下「正确答案」有用得多。** 判题机不会放过任何一个边界情况，这正是它比课后题有价值的地方。

### 刷题顺序

按洛谷官方的「入门」题单走，不要跳。前 20 题会有点难受，之后就顺了。
