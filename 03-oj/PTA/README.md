## 这几题栽在哪

| 题 | 坑 |
|---|---|
| L1-002 | 沙漏形状、层数公式 `k = sqrt((n+1)/2)`、`used = 2k²-1` 全写对了，n=1~1000 逐字节比对 1000 组形状 0 差异；错在最后一句加了 `if (remaining != 0)`，剩余为 0 时什么都不输出，而题目要求**无条件**输出剩余数。会挂的正好是 `2k²-1` 那 22 个 n |
| L1-003 | 第一版 `%c` 打次数、`s[i] - '0'` 多减一次、`i < 9` 少了 9、`char` 当计数器溢出（1000 打成 -24）；第二版改数组下标后循环按 1005 跑，越过 `'\0'` 变成 `s[-48]++` 越界写，还多写了「读 1005 次」的循环，终端里手打时第 2 次 `scanf` 死等 |
| 3.1 | 这题三个条件**可能同时成立**（105 同时被 3、5、7 整除），写成 `if / else if` 串起来就只输出一个 |
| 3.4 | 两个「全部检查」分支的代码一模一样；`first` 实际是「坏轮胎个数」，名字读不出来 |
| 3.6 | 两处 `scanf` 都没检查返回值，输入坏掉时拿着栈上垃圾继续算 |
| 3.7 | 变量 `t` 先当开关判断、再被赋成系数，原值没了 —— 一个变量兼职两件事 |
| 3.12 | 第一版把「输入负数」塞在第四个 `else if` 里，但前面 `>`、`<`、`==` 已穷尽所有情况，那个分支永远执行不到；第二版拆成独立 `if` 后条件可达了，却忘了 `break`，循环跑到读不到输入才停 |
| 3.13 | 归零那段写成 `if (fabs(x2) < 0.005) x1 = 0.00;` —— 判的是 `x2`、改的是 `x1`。输入 `1 -3 0`（两根 3 和 0）输出 `0.00 / 0.00`，把 3 吃掉了 |
| 3.15 | `char str[3]` 对输入 `"13"` 刚好卡在边界；2~9 分支只看 `str[0]`，1x 分支却用整串比较，两种判法不一致 |

## 这一组要注意的

- **题目说要输出，就必须输出，哪怕值是 0。** L1-002 就栽在这上面：自己判断「0 没什么好打印的」，判题机不认。
- **循环次数 = 数据有多少，不是数组开多大。** L1-003 两个错（越界 `s[-48]`、`scanf` 死等）都是把「1005」当成了循环次数。
- **`-'0'` 只对字符用。** 手里已经是数字（次数）还去减 48，只会得到负数。
- **换写法时要重新检查边界。** `switch` 没匹配项什么都不做，换成 `s[num[i]-'0']++` 之后就没有这层保险了 —— 改了实现，要重新想一遍「下标可能是什么值」。
- **管道测不出交互问题。** `echo "数据" | ./程序` 和手打输入是两套 stdin 行为，测得出的和测不出的不一样。
- **分支要穷尽、要按「次数 / 类别」先分。** 3.13 的一元二次方程最容易漏 `a == 0` 的退化情况，`a == 0 && b == 0` 又是另一种。
- **「标记 + break」是两件事。** 3.12 记了 `first = 1` 却没跳出循环，标记本身不会让程序停下来。
- **`=` 和 `==` 能编译过。** 3.4 早期版本 `if (first = 2)` 把赋值当条件，`-Wall` 会警告 `suggest parentheses around assignment used as truth value` —— 看到这条一定要查。
