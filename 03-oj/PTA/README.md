## 这两题各自栽在哪

| 题 | 坑 |
|---|---|
| L1-002 | 沙漏形状、层数公式 `k = sqrt((n+1)/2)`、`used = 2k²-1` 全写对了，n=1~1000 逐字节比对 1000 组形状 0 差异；错在最后一句加了 `if (remaining != 0)`，剩余为 0 时什么都不输出，而题目要求**无条件**输出剩余数。会挂的正好是 `2k²-1` 那 22 个 n |
| L1-003 | 第一版 `%c` 打次数、`s[i] - '0'` 多减一次、`i < 9` 少了 9、`char` 当计数器溢出（1000 打成 -24）；第二版改数组下标后循环按 1005 跑，越过 `'\0'` 变成 `s[-48]++` 越界写，还多写了「读 1005 次」的循环，终端里手打时第 2 次 `scanf` 死等 |

## 这一组要注意的

- **题目说要输出，就必须输出，哪怕值是 0。** L1-002 就栽在这上面：自己判断「0 没什么好打印的」，判题机不认。
- **循环次数 = 数据有多少，不是数组开多大。** L1-003 两个错（越界 `s[-48]`、`scanf` 死等）都是把「1005」当成了循环次数。
- **`-'0'` 只对字符用。** 手里已经是数字（次数）还去减 48，只会得到负数。
- **换写法时要重新检查边界。** `switch` 没匹配项什么都不做，换成 `s[num[i]-'0']++` 之后就没有这层保险了 —— 改了实现，要重新想一遍「下标可能是什么值」。
- **管道测不出交互问题。** `echo "数据" | ./程序` 和手打输入是两套 stdin 行为，测得出的和测不出的不一样。
